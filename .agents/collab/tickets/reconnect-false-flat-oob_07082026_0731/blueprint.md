# Ticket Resolution Blueprint — reconnect-false-flat-oob_07082026_0731
**Ticket Directory:** `.agents/collab/tickets/reconnect-false-flat-oob_07082026_0731/`

## Bug Summary
On a reconnect/restart the position-recovery path reads ib_insync's **in-memory** `IB.positions()` cache (via `get_cl_position` → `self.ib.positions()`), which is populated asynchronously by the account-update subscription and issues **no request / no wait**. `connectAsync` only awaits `reqPositions` up to the 5s connect timeout and, on timeout, merely logs and continues with an **empty** cache. So a slow/thundering-herd reconnect returns a clean connection but zero positions → `get_position()==0` → `_recover_inherited_position` (and two sibling sites) treat it as an **out-of-band close** and **cancel the live protective legs** of a still-open position, marking it `CLOSED_OOB_UNRECOVERED`. Incident 2026-07-08 07:27:28 PT: SI child cancelled SL(14)/TP(13) on a still-open full-size SIU6 short → naked ~$296k position, unmanaged. Latent flaw (unwaited read `e975bbef` 2026-02-24; `==0` OOB branch `2e55132e` 2026-03-26); **not a recent regression**. Severity HIGH. Impact-Reviewer: APPROVE, no human-auth (single-component, live-exec seam, parity-safe).

## Target Files
- `src/live_execution/interfaces/execution_interface.py` — new **non-abstract default** `get_position_settled(symbol) -> int` (mirror `get_cached_position`: base raises `NotImplementedError`, no signature change to `get_position`).
- `src/live_execution/ibkr_client.py` — `IBKRConnectionManager.get_position_settled(symbol)`: force a **settled** snapshot via `self.ib.run(asyncio.wait_for(self.ib.reqPositionsAsync(), _POSITION_SETTLE_TIMEOUT))` then the existing `contract_matches` loop. **Never** blocking `reqPositions()` (RequestTimeout=0 → infinite hang) and **never** `ib.sleep(_SETTLE)` as the settle mechanism. Raises on timeout/error (the fail-closed trigger).
- `src/live_execution/adapters/ibkr_execution.py` — `get_position_settled` → `manager.get_position_settled`.
- `src/live_execution/adapters/simulated_execution.py` — `get_position_settled` → return the true sim `_position` (honest, never fabricated flat).
- `src/live_execution/live_trader.py` — new helper `_confirm_settled_position(symbol) -> Optional[int]` (None = could NOT confirm → caller MUST fail closed). Wire into three cancel/close-on-zero sites: `_recover_inherited_position`, `_check_time_barrier` (only when `==0` while a trade is tracked), `_cancel_orphaned_orders_on_startup` (before cancelling on `==0`). **Kill switch `_check_naked_position` is intentionally NOT touched** — its `==0` branch already fails safe (returns, cancels nothing).

## Required Changes
1. **Settled read primitive.** `get_position_settled` issues a fresh `reqPositionsAsync()` bounded by `asyncio.wait_for(..., _POSITION_SETTLE_TIMEOUT)` (deterministic resolve on `positionEnd`), then matches by symbol+tradingClass exactly like `get_cl_position`. On `asyncio.TimeoutError`/any error it RAISES (does not fall back to the stale cache). Safe only on the main thread with the loop idle (startup recovery / 5-min poll) — the same sanctioned context as `_check_contract_rollover`.
2. **`_confirm_settled_position(symbol)`** wrapper on LiveTrader: returns the settled int; on `NotImplementedError` (adapter without a settled read) falls back to `get_position`; on any other exception logs LOUD (ERROR + `_emit_health_event("position-flat-unconfirmed", …)`) and returns **None**. None ⇒ caller retains protection.
3. **`_recover_inherited_position`:** when the ledger has an OPEN trade and the first `get_position()==0`, do NOT act on it. Call `_confirm_settled_position`: if it returns **0** → genuine OOB close (unchanged `_recover_oob_close` + cooldown seed); if it returns **>0/<0** (stale cache) → fall through to the normal restore branch; if it returns **None** (unconfirmed) → **fail closed**: LOUD + health event, restore in-memory tracking and let `_verify_and_heal_protective_legs` (idempotent — both-legs-resting = no-op) keep protection; never cancel legs, never mark OOB.
4. **`_check_time_barrier`:** gate the existing `==0` OOB block behind a settled re-verify **only** when `current_position==0 and self._active_trade_id is not None`. settled 0 → existing OOB/reset; settled nonzero → treat as still in-position; settled None → return False this cycle (retain, LOUD), defer.
5. **`_cancel_orphaned_orders_on_startup`:** before treating resting orders as orphans on `ibkr_pos==0`, confirm settled. settled nonzero → return (real position, don't cancel its legs); settled None → return without cancelling (fail closed, LOUD); settled 0 → proceed to cancel genuine orphans.
6. **Contract:** add health kind `position-flat-unconfirmed` to the test-enforced `_ALLOWED_KINDS` set and SKILL.md triage (retain-protection/defer semantics — NOT naked, NOT a crash).

## Test Plan (TDD RED → GREEN, `conda run -n trader python -m pytest`)
- **RED** (reproduces incident): ledger OPEN short; `get_position` returns 0 but `get_position_settled` returns -1 → assert current code cancels legs / marks `CLOSED_OOB_UNRECOVERED`. **GREEN**: with re-verify, `_recover_oob_close` NOT called, legs NOT cancelled, position restored.
- **Fail-closed**: `get_position_settled` raises `TimeoutError` → protection retained (no cancel, no OOB), LOUD `position-flat-unconfirmed`.
- **True-OOB regression**: `get_position`=0 AND `get_position_settled`=0 → OOB path still fires (unchanged).
- **Primitive**: IBKR adapter drives `reqPositionsAsync` under `wait_for` (not blocking `reqPositions`, not `ib.sleep`); sim returns true `_position`; interface default raises `NotImplementedError`.
- **time-barrier** + **startup-sweep**: false-flat while a position is really present → no cancel; genuine flat → unchanged.
