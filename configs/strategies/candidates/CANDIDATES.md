Those Rank_* JSON files are generated by the TopKTracker class inside the agent/strategy_optimizer.py script.

Whenever you run a strategy optimization sweep (either manually or via the batch post-optimizer), the script tests hundreds of different parameter combinations (like entry thresholds, stop-loss multipliers, and trailing stops). As it runs, it maintains a running leaderboard of the top 5 absolute best configurations based on their "Consistency Score" (Annualized Sharpe).

At the end of the optimization run, it dumps the top 5 configurations into the configs/strategies/candidates folder.

What the Filename Means
The filename encodes the context of how that configuration performed:

Rank_5: It was the 5th best configuration found during that specific optimization run.
Trial_996: It was discovered on the 996th Optuna trial (meaning it searched through nearly a thousand variations before landing on this one).
Score_1.09: It achieved a Consistency Score (Sharpe ratio equivalent) of 1.09 during the simulated backtest.
What the File Represents
Each file is a completely standalone, ready-to-use strategy configuration file. Inside, you'll see the exact optimized values injected directly into the JSON (for example, in the file you're viewing, it set "tp_atr_mult": 8.5 and "sl_atr_mult": 3.5).

If you find a candidate in that folder that you like, you can simply rename it, move it up one level into the configs/strategies/ folder, and run your live trader or backtester with it immediately!
